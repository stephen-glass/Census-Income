# Census Income Analysis

## Overview

This project investigates the factors associated with income levels using **census data** and statistical analysis. The project involved exploring relationships between demographic and socioeconomic variables and income, with statistical modelling used to identify important factors associated with income.

## My Contribution

As part of the group project, I was responsible for the **SAS-based data analysis and modelling**. Other members of the group contributed analysis using R.

## Methods

* Data preparation and exploratory analysis
* Statistical modelling
* Analysis of relationships between demographic and socioeconomic variables
* Interpretation and presentation of results

## Tools

**SAS · R · Statistical Modelling · Census Data**
